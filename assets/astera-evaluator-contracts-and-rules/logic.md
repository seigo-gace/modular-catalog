# Logic

判定Request・Result・KB Record、Profile、Rubric、Blocking RuleのVersion固定定義を所有する。

入力を所有境界で検証し、決定論的な規則または明示された外部契約だけで処理する。下位から上位の具象実装を参照せず、失敗を成功値へ変換しない。対象Sourceは`src/quality-completion-evaluator/contracts/evaluation-request.v1.schema.json`、`src/quality-completion-evaluator/contracts/evaluation-result.v1.schema.json`、`src/quality-completion-evaluator/contracts/kb-record.v1.schema.json`、`src/quality-completion-evaluator/profiles/configuration.profile.v1.json`、`src/quality-completion-evaluator/profiles/design.profile.v1.json`、`src/quality-completion-evaluator/profiles/implementation.profile.v1.json`、`src/quality-completion-evaluator/profiles/incident-resolution.profile.v1.json`、`src/quality-completion-evaluator/profiles/knowledge.profile.v1.json`、`src/quality-completion-evaluator/profiles/operation.profile.v1.json`、`src/quality-completion-evaluator/profiles/other.profile.v1.json`、`src/quality-completion-evaluator/profiles/research.profile.v1.json`、`src/quality-completion-evaluator/profiles/test.profile.v1.json`、`src/quality-completion-evaluator/quality/quality-rubric.v1.json`、`src/quality-completion-evaluator/completion/completion-rubric.v1.json`、`src/quality-completion-evaluator/blocking/blocking-rules.v1.json`。
